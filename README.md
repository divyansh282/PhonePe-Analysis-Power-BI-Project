# 📊 PhonePe Business Dashboard | Power BI, DAX & Excel

A recruiter-friendly **PhonePe-style payments analytics dashboard** built in **Microsoft Power BI**, designed to analyze transaction performance, customer behavior, payment status, and service-level trends.

The dashboard transforms raw transaction data into interactive KPIs and business insights using **Power BI, DAX, and Excel**.


## 🚀 Project Overview

This project analyzes a large-scale digital payments dataset containing **300K+ transactions**, **₹3.47bn in transaction value**, and **108K unique users**.

The dashboard provides an interactive view of payment performance and user behavior, allowing users to filter transactions by payment status and explore trends across multiple dimensions.

### Key Metrics

| KPI | Value |
|---|---:|
| 💳 Total Transactions | **300K+** |
| 💰 Total Transaction Value | **₹3.47bn** |
| 👥 Unique Users | **108K** |
| ✅ Successful Rate | **96.00%** |
| 📈 MoM Transaction Growth | **8.97%** |
| 📈 MoM Value Growth | **8.98%** |

## 🎯 Business Objectives

The dashboard was created to:

- Monitor overall payment transaction performance
- Track transaction value and month-over-month growth
- Analyze successful, pending, and failed transactions
- Understand customer behavior across age segments
- Compare weekday and weekend transaction activity
- Identify top users by transaction value
- Analyze transaction value across different services
- Convert raw transaction data into actionable business insights

---

## 📌 Dashboard Features

### 1. KPI Overview

High-level KPI cards provide an at-a-glance view of:

- Total Transactions
- Total Transaction Value
- Unique Users
- Successful Transaction Rate
- Month-over-Month Growth

---

### 2. Transaction Status Analysis

Interactive status filtering allows analysis of:

- ✅ Successful transactions
- ⏳ Pending transactions
- ❌ Failed transactions

This makes it easier to understand payment performance and transaction outcomes.

---

### 3. Transactions Over Time

The time-series visualization tracks transaction volume and transaction value across months.

This helps identify:

- Monthly transaction patterns
- Peaks and declines
- Changes in transaction value
- Overall payment activity trends

---

### 4. Age Segment Contribution

A donut chart breaks down transaction contribution across customer age groups, including:

- Gen X
- Millennials
- Gen Z
- Boomers

This provides a view of how different customer segments contribute to payment activity.

---

### 5. Service Transaction Value Analysis

Transaction value is analyzed across major services such as:

- Loans
- Insurance
- Money Transfer
- Recharge & Bills

This helps identify which services contribute most significantly to overall transaction value.

---

### 6. Top 5 Users

A ranking visual highlights the **top 5 users by transaction value**, making it easier to identify high-value customers.

---

### 7. Weekday vs Weekend Usage

The dashboard compares transaction activity between:

- Weekdays
- Weekends

The analysis indicates that **weekday transactions account for approximately 71.6%**, compared with **28.4% on weekends**.

---

## 💡 Key Insights

Based on the dashboard analysis:

- The platform processed **300K+ transactions** worth approximately **₹3.47bn**.
- The overall successful transaction rate is **96%**.
- **Weekdays account for the majority of transaction activity** at approximately 71.6%.
- **Loans contribute the highest transaction value** among the analyzed services.
- Age-segment analysis provides visibility into the contribution of different customer demographics.
- Top-user analysis helps identify customers generating significant transaction value.
